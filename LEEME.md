# NEON//FORUM

Un foro para hablar de videojuegos, IA, arte digital y otras cosas que nos gustan de internet.

Lo hice para practicar PHP y MySQL y fui añadiendo funciones hasta tener una web que se puede usar.

## Qué se puede hacer

- Registrarse e iniciar sesión.
- Ver los temas organizados por secciones.
- Crear temas y responder con mensajes y emoticonos.
- Personalizar el perfil con avatar y firma.
- Borrar tus propios mensajes.

## Cómo lo hice

Programé el HTML, PHP, JavaScript y las consultas SQL. Usé IA como apoyo para algunas mejoras y correcciones. El CSS está generado con IA siguiendo mis indicaciones de diseño.

## Para probarlo en local

Necesitas PHP y MySQL; yo usé XAMPP. Hay que configurar la conexión y preparar la base de datos con las tablas del foro. Las credenciales del servidor no están incluidas.

Es un proyecto de aprendizaje y todavía hay cosas que quiero mejorar.
